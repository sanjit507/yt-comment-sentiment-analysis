Workflow

  1. Open a YouTube video page.
  2. Click the extension icon and scan the current tab.
  3. The extension extracts visible comments.
  4. Comments are sent to the local API for sentiment scoring.
  5. Results appear here for deeper review.

Local-first notes

This extension is intentionally local-first. It avoids remote dependencies, making it easier to demo, debug, and run on a developer machine.
