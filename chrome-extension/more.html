How it works

  1. Open a YouTube video page.
  2. Click the extension icon and scan the current tab.
  3. The extension extracts visible comments.
  4. Comments are sent to the local Flask API for sentiment scoring.
  5. Results are displayed back in the popup.

Production notes

This extension is intentionally local-first. It avoids remote dependencies, making it easier to demo, debug, and deploy on a developer machine.

Supported pages

  • YouTube watch pages
  • YouTube Shorts
  • YouTube Live pages
